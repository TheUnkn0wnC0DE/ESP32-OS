Quality release for ESP32-OS 1.0.3 on the Waveshare ESP32-P4-WIFI6-Touch-LCD-5. The images are built for chip revision v1.x (360 MHz).

## Changes since 1.0.3

- **Weather:** new app with current weather and a 5-day forecast from Open-Meteo (no API key). Choose the place by touch in the app or in *Settings → Weather place*; without Wi-Fi it says so.
- **Browser:** CSS variables (`var()`), `calc()` with one unit, the space syntax of `rgb()`/`hsl()` and logical properties such as `margin-inline-start` now work; ES modules and import maps are skipped like in a browser without modules; new `document.currentScript`, `ResizeObserver`, `IntersectionObserver`, `new Image()` and `performance.timing`. JavaScript may use up to 6 MB as long as 3 MB stay free for the page. On 30 well-known pages: JavaScript errors 61 → 17, CSS declarations dropped because of `var()` 8677 → about 700; 22 pages load, 8 are cut off at 512 KB of HTML, none ends early.
- **Memory:** opening the Start menu no longer leaves about 108 KB of PSRAM behind each time (about 1 MB per hour of heavy use, also in 1.0.3), and starting a program no longer leaves a few bytes of internal RAM behind (about 7–9 KB per 75 minutes, also in 1.0.3); programs no longer start when system memory is almost full. 75-minute endurance run with all programs, the Start menu, the browser and sleep mode: 0 crashes, internal RAM and PSRAM stable.
- **Stability:** a program that is force-closed while it holds its own memory lock is now really ended; before, its memory stayed reserved and the browser could no longer start.
- **Everyday use:** typing in Notes about 31 to 33 frames per second instead of 24 to 30; a program that cannot start shows why; the music player also plays WAV and MIDI files; windows of original KolibriOS programs no longer open behind the taskbar; the image demo no longer crashes on a damaged picture file; the console no longer complains about a missing start script; long taskbar titles end with "..".

## Install

On 1.0.1, 1.0.2 or 1.0.3: *Settings → System → Check for updates*.

**espflash:** download the files below, check them against `SHA256SUMS`, then:

```
espflash write-bin 0x2000   bootloader.bin
espflash write-bin 0x8000   partition-table.bin
espflash write-bin 0x10000  otadata-leer.bin
espflash write-bin 0x20000  esp32os.bin
espflash write-bin 0xC00000 doomapp.bin
espflash write-bin 0xE00000 quakeapp.bin
```

Settings and saved Wi-Fi networks on the board are kept. Game data is not included: copy the shareware files `DOOM1.WAD` to `ESP32-OS/doom/` and `pak0.pak` to `ESP32-OS/quake/` on the microSD card. Boards with chip revision v3.x need a build from source with the v3 profile (see the README). The web flasher installs 1.0.4.

## Known issues

- **License of the binary images:** the images combine GPL-2.0 code (NetSurf, KolibriOS) with Apache-2.0 code (ESP-IDF, esp_hosted). Whether binaries may be distributed in this combination has not been settled. The source code in the repository is not affected.
- Wi-Fi passwords are stored unencrypted in flash (no flash encryption, no eFuses).
- Scrolling reaches 25–29 frames per second; the display shows frames at 55 Hz and a frame that needs more than 18 ms waits for the next refresh.
- The browser has 10 MB of memory: 6 to 9 of the 30 test pages run out of JavaScript memory and are shown without JavaScript, pages with more than 512 KB of HTML are cut off. No rounded corners, shadows, transitions or CSS grid. At the end of very large pages the browser can stop responding for up to half a minute while it cleans up its memory. On html.duckduckgo.com the logo is missing.
- The PDF viewer shows text in the system font, opens files up to 4 MB and does not decode CCITT, JBIG2 or JPEG 2000 images.
- All programs share one address space. A faulty program is stopped and reported, but can still disturb the system.
- No battery gauge or camera support. The Wi-Fi co-processor keeps its factory firmware.
