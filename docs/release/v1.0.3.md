Stability release for ESP32-OS 1.0.2 on the Waveshare ESP32-P4-WIFI6-Touch-LCD-5. The images are built for chip revision v1.x (360 MHz).

## Changes since 1.0.2

- **Stability and memory:** three 75-minute endurance runs on the board with all programs, the start menu and the browser: 0 crashes, 0 restarts. Internal RAM under load about 210 KB free instead of 86 KB. Large programs get their memory from a pool reserved at start-up, so PSRAM no longer breaks into small pieces; if memory is full, a program does not start and says so instead of taking the system down.
- **Crash protection:** a hardware fault in a program ends only that program. This protection never triggered on the board in 1.0.2. After a crash and restart, the message names the reason and the memory state.
- **Browser:** tapping the Start button while the browser is open no longer crashes the system; starting the browser a second time no longer crashes the board. A page that cannot load shows a readable reason. DNS falls back to 1.1.1.1. Measured on 30 well-known pages: 21 load, 7 are cut off at 512 KB of HTML, 2 run out of memory; no crash.
- **Windows:** original KolibriOS programs (PasswordGen, TinyHashView, example GUI) no longer draw into the taller touch title bar; all windows have complete title bars and borders. A window's taskbar entry appears together with the window. Tapping the Start button again closes the menu.
- **File manager:** recycle bin with restore; scrolling is smoother (25 instead of 18 frames per second).
- **Console and shell:** the KolibriOS shell runs in a native console with redirection (`>`, `>>`, `<`), pipes (`|`) and new commands cat, grep, wc, head, tail and sort. New Matrix program.
- **Sleep mode** from the Start menu; a tap wakes the board, Wi-Fi reconnects.
- First-run wizard: closing it with the X counts as done. Firmware update: readable connection errors.

## Install

On 1.0.1 or 1.0.2: *Settings → System → Check for updates*.

**espflash:** download the files below, check them against `SHA256SUMS`, then:

```
espflash write-bin 0x2000   bootloader.bin
espflash write-bin 0x8000   partition-table.bin
espflash write-bin 0x10000  otadata-leer.bin
espflash write-bin 0x20000  esp32os.bin
espflash write-bin 0xC00000 doomapp.bin
espflash write-bin 0xE00000 quakeapp.bin
```

Settings and saved Wi-Fi networks on the board are kept. Game data is not included: copy the shareware files `DOOM1.WAD` to `ESP32-OS/doom/` and `pak0.pak` to `ESP32-OS/quake/` on the microSD card. Boards with chip revision v3.x need a build from source with the v3 profile (see the README). The web flasher stays on 1.0.1 for now.

## Known issues

- **License of the binary images:** the images combine GPL-2.0 code (NetSurf, KolibriOS) with Apache-2.0 code (ESP-IDF, esp_hosted). Whether binaries may be distributed in this combination has not been settled. The source code in the repository is not affected.
- Wi-Fi passwords are stored unencrypted in flash (no flash encryption, no eFuses).
- Internal RAM still drops by about 7–8 KB per hour of heavy use (not yet attributed); with 210 KB free this matters only after many hours.
- Scrolling reaches 25–29 frames per second; the display shows frames at 55 Hz and a frame that needs more than 18 ms waits for the next refresh.
- The browser has 10 MB of memory; pages with more than 512 KB of HTML are cut off.
- The PDF viewer shows text in the system font, opens files up to 4 MB and does not decode CCITT, JBIG2 or JPEG 2000 images.
- All programs share one address space. A faulty program is stopped and reported, but can still disturb the system.
- No battery gauge or camera support. The Wi-Fi co-processor keeps its factory firmware.
