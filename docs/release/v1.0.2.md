Bugfix release for ESP32-OS 1.0.1 on the Waveshare ESP32-P4-WIFI6-Touch-LCD-5. The images are built for chip revision v1.x (360 MHz).

## Changes since 1.0.1

- **Quake: "New Game" works.** It aborted with "progs.dat has wrong version number": the firmware treated the end of the PAK directory as the end of the file, and in the shareware `pak0.pak` the game code lies behind the directory.
- **On-screen keyboard:** a key is drawn smaller and darker while a finger rests on it (every key, including Shift, Backspace, Space and Enter). Only that key is redrawn; typing 14 characters per second loses no character.
- **Browser:** a page no longer takes the whole system down when internal RAM runs out. A new connection opens only with 32 KB of internal RAM left, otherwise that resource fails with "not enough memory". Closed TCP connections stay 10 s instead of 120 s in TIME_WAIT.

## Install

On 1.0.1: *Settings → System → Check for updates*. On 1.0, Settings does not open shortly after power-on; install over the cable instead.

**Web flasher:** open https://theunkn0wnc0de.github.io/ESP32-OS/ in Chrome or Edge on a desktop computer, connect the board's USB TO UART port, click *Connect*, choose the board's serial port and click *Install*.

**espflash:** download the files below, check them against `SHA256SUMS`, then:

```
espflash write-bin 0x2000   bootloader.bin
espflash write-bin 0x8000   partition-table.bin
espflash write-bin 0x10000  otadata-leer.bin
espflash write-bin 0x20000  esp32os.bin
espflash write-bin 0xC00000 doomapp.bin
espflash write-bin 0xE00000 quakeapp.bin
```

Without *Erase device* (web flasher) and with espflash, settings and saved Wi-Fi networks on the board are kept. Game data is not included: copy the shareware files `DOOM1.WAD` to `ESP32-OS/doom/` and `pak0.pak` to `ESP32-OS/quake/` on the microSD card. Boards with chip revision v3.x need a build from source with the v3 profile (see the README).

## Known issues

- **License of the binary images:** the images combine GPL-2.0 code (NetSurf, KolibriOS) with Apache-2.0 code (ESP-IDF, esp_hosted). Whether binaries may be distributed in this combination has not been settled. The source code in the repository is not affected.
- Wi-Fi passwords are stored unencrypted in flash (no flash encryption, no eFuses).
- The browser has 10 MB of memory. Large web applications do not load; some web APIs are missing.
- The PDF viewer shows text in the system font, opens files up to 4 MB and does not decode CCITT, JBIG2 or JPEG 2000 images.
- The image viewer needs 5.9 s for a 12-megapixel photo and 11.4 s for 48 megapixels; progressive JPEGs of 48 megapixels are refused.
- All programs share one address space. A faulty program is stopped and reported, but can still disturb the system.
- No standby, battery gauge or camera support (planned for 1.1). The Wi-Fi co-processor keeps its factory firmware.
