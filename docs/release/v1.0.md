First release of ESP32-OS, a KolibriOS-compatible OS that runs natively on the Waveshare ESP32-P4-WIFI6-Touch-LCD-5. The images are built for chip revision v1.x (360 MHz).

## Install

**Web flasher:** open https://theunkn0wnc0de.github.io/ESP32-OS/ in Chrome or Edge on a desktop computer, connect the board's USB TO UART port and click *Install*. Without *Erase device*, settings and saved Wi-Fi networks on the board are kept.

**espflash:** download the files below, check them against `SHA256SUMS`, then:

```
espflash write-bin 0x2000   bootloader.bin
espflash write-bin 0x8000   partition-table.bin
espflash write-bin 0x10000  otadata-leer.bin
espflash write-bin 0x20000  esp32os.bin
espflash write-bin 0xC00000 doomapp.bin
espflash write-bin 0xE00000 quakeapp.bin
```

Game data is not included. Copy the shareware files `DOOM1.WAD` to `ESP32-OS/doom/` and `pak0.pak` to `ESP32-OS/quake/` on the microSD card.

Boards with chip revision v3.x need a build from source with the v3 profile (see the README).

## Files

| File | Size (bytes) | Purpose |
|---|---|---|
| `esp32os.bin` | 5,699,056 | ESP32-OS, 91.5 % of its flash slot; also used by the update over Wi-Fi |
| `esp32os.bin.sha256` | 78 | checksum for the update over Wi-Fi |
| `doomapp.bin` | 1,698,448 | Doom program |
| `quakeapp.bin` | 1,713,408 | Quake program |
| `bootloader.bin`, `partition-table.bin`, `otadata-leer.bin` | 24,160 / 3,072 / 8,192 | first installation |
| `manifest.json` | 1,555 | web flasher |
| `SHA256SUMS` | 485 | checksums of all files |

## Contents

- KolibriOS system functions in Rust; original KolibriOS C programs (PasswordGen, TinyHashView, clayer samples) run unchanged.
- Touch desktop with taskbar, start menu, gestures and on-screen keyboard (Swiss German, US); English and German interface.
- File manager, image viewer, PDF viewer, settings, notes, calculator, clock, calendar, MP3 player, task manager, screenshot tool.
- Wi-Fi 6 through the ESP32-C6; NetSurf 3.11 browser with HTTPS and JavaScript (QuickJS-ng).
- Pudding-Panik, Würfelwelt, Doom and Quake, started from the desktop.
- Update over Wi-Fi from GitHub releases with SHA-256 check and automatic rollback.

Measured values and their evidence are listed in the README under "Facts".

## Known issues

- **Settings does not open shortly after power-on.** It reserves slightly more than 12 MB in one block; after power-on the largest free block is exactly 12 MB. Fixed in the source code (6 MB), the fix comes with the next release.
- **License of the binary images:** the images combine GPL-2.0 code (NetSurf, KolibriOS) with Apache-2.0 code (ESP-IDF, esp_hosted). Whether binaries may be distributed in this combination has not been settled. The source code in the repository is not affected.
- Wi-Fi passwords are stored unencrypted in flash (no flash encryption, no eFuses).
- The browser has 10 MB of memory. Large web applications do not load; some web APIs are missing.
- The PDF viewer shows text in the system font, opens files up to 4 MB and does not decode CCITT, JBIG2 or JPEG 2000 images.
- The image viewer needs 5.9 s for a 12-megapixel photo and 11.4 s for 48 megapixels; progressive JPEGs of 48 megapixels are refused.
- All programs share one address space. A faulty program is stopped and reported, but can still disturb the system.
- No standby, battery gauge or camera support (planned for 1.1). The Wi-Fi co-processor keeps its factory firmware.
