# ESP32-OS v1.0

KolibriOS, running natively on the **Waveshare ESP32-P4-WIFI6-Touch-LCD-5**:
a touch desktop with everyday apps, Wi-Fi 6, the NetSurf web browser with
JavaScript, and games – no emulator, the KolibriOS system functions are
re-implemented in Rust and original KolibriOS C programs run unchanged.

> ESP32-OS is an experimental hobby project, vibecoded with Claude Code and
> tested on the real board. Expect rough edges.

## Highlights

- **Desktop:** icons, taskbar with Wi-Fi signal and clock, start menu,
  on-screen keyboard (Swiss German, US), gestures (tap, long press, swipe, pinch),
  screenshots, setup assistant on first start.
- **Apps:** file manager, image viewer (JPEG via the P4's hardware decoder,
  PNG, GIF, BMP), settings, text editor, calculator, clock with alarm and
  timer, calendar, MP3 player, task manager, PDF viewer (scroll,
  page through, pinch-zoom).
- **KolibriOS programs, unchanged:** PasswordGen and TinyHashView (MD5,
  SHA-1, SHA-256 checksums) in *Start → More programs*, with KolibriOS-style
  notifications.
- **Wi-Fi 6** through the ESP32-C6 co-processor: scan, connect by touch,
  remembered networks, time via NTP.
- **Web browser:** NetSurf 3.11 with HTTPS, tabs, bookmarks, history,
  downloads, zoom, text selection, forms with the on-screen keyboard and
  JavaScript (QuickJS-ng): DOM, events, timers, fetch/XMLHttpRequest,
  cookies, localStorage. Pages whose scripts are too heavy are reloaded
  without JavaScript automatically.
- **Games:** Doom and Quake (shareware data from the microSD card), plus
  Pudding-Panik and Würfelwelt – all started from the desktop and back with
  the home button.
- **Updates over Wi-Fi:** *Settings → System → Check for updates* installs
  the newest GitHub release into the second firmware slot (HTTPS with
  certificate check, SHA-256 checksum); if the new version does not start,
  the board rolls back automatically.

## Installing

**Web flasher** (Chrome or Edge on a desktop computer): open the ESP32-OS
web flasher, connect the board's **USB TO UART** port and click *Install*.

**Manually** with [espflash](https://github.com/esp-rs/espflash) and the
files attached to this release (check them against `SHA256SUMS` first):

```
espflash write-bin 0x2000   bootloader.bin
espflash write-bin 0x8000   partition-table.bin
espflash write-bin 0x10000  otadata-leer.bin
espflash write-bin 0x20000  esp32os.bin
espflash write-bin 0xC00000 doomapp.bin
espflash write-bin 0xE00000 quakeapp.bin
```

The firmware is built for **chip revision v1.x** (360 MHz). On boards with
a v3.x chip, build from source with the v3 profile (see the README).

**Game data** is not included: copy the Doom shareware `DOOM1.WAD` to
`ESP32-OS/doom/` and the Quake shareware `pak0.pak` to `ESP32-OS/quake/` on
the microSD card. The games show a notice with the license when the data is
missing.

## Files

| File | Purpose |
|---|---|
| `esp32os.bin` | ESP32-OS (also used by the Wi-Fi update) |
| `esp32os.bin.sha256` | checksum for the Wi-Fi update |
| `doomapp.bin`, `quakeapp.bin` | game programs |
| `bootloader.bin`, `partition-table.bin`, `otadata-leer.bin` | first installation |
| `SHA256SUMS` | checksums of all files |

## Known limitations

- **Wi-Fi passwords are stored unencrypted** in the internal flash (no flash
  encryption, no eFuses burned).
- The browser handles simple and medium pages; large web apps can exceed the
  10 MB browser memory. Some web features are missing (see `docs/development/PLAN.md`,
  "B7, Grenzen der Web-Funktionen").
- The PDF viewer shows text in the system font (embedded fonts are not
  rasterised) and opens files up to 4 MB; scanned pages using CCITT fax,
  JBIG2 or JPEG 2000 show a grey placeholder.
- Battery level, standby, iTWT power saving and a camera app are planned
  for a later update (v1.1).
- The Wi-Fi co-processor runs its factory firmware; updating it needs a
  cable (planned for v1.1).
- All programs share one address space; a faulty C program can disturb the
  system (crashes are caught and reported).
