ESP32-OS 1.0.5 for the Waveshare ESP32-P4-WIFI6-Touch-LCD-5: Ogg Vorbis in the music player and a new App store. The images are built for chip revision v1.x (360 MHz).

## Changes since 1.0.4

- **Music player:** plays Ogg Vorbis files (.ogg, .oga) with stb_vorbis 1.25 (MIT / public domain). Broken or cut-off files end with a message or at the last readable part, never with a crash.
- **App store (new):** Doom and Quake can be removed and installed again over Wi-Fi from the latest GitHub release (HTTPS with certificate check, SHA-256 from `SHA256SUMS`); removing asks for a second tap. Pudding Panic, Cube World, PasswordGen, TinyHashView and the example programs can be removed from and put back into the Start menu and desktop – they stay part of the firmware, because ESP32-OS cannot load program code at run time yet. The core system cannot be removed.
- **App store safety:** a failed or wrong download leaves the game marked as not installed; Wi-Fi update and App store never write to flash at the same time.
- **Browser:** the JavaScript button is translated ("No JS" / "With JS").
- **Browser:** no more half-minute freezes at the end of very large pages. The browser's memory manager now finds free blocks in a tree sorted by address (same placement as before, so no extra waste) instead of walking a long list. Measured on 30 test pages: no page ends early, no freeze, no restart.
- **Stability:** with system memory almost full, the system no longer stops; programs and windows are refused instead (40-minute test with only 600 KB of system memory left: 0 crashes). In that extreme case the "program not started" message cannot be shown either; the reason is in the log.

## Install

On 1.0.1 to 1.0.4: *Settings → System → Check for updates*.

**espflash:** download the files below, check them against `SHA256SUMS`, then:

```
espflash write-bin 0x2000   bootloader.bin
espflash write-bin 0x8000   partition-table.bin
espflash write-bin 0x10000  otadata-leer.bin
espflash write-bin 0x20000  esp32os.bin
espflash write-bin 0xC00000 doomapp.bin
espflash write-bin 0xE00000 quakeapp.bin
```

Settings and saved Wi-Fi networks on the board are kept. Game data is not included: copy the shareware files `DOOM1.WAD` to `ESP32-OS/doom/` and `pak0.pak` to `ESP32-OS/quake/` on the microSD card. Boards with chip revision v3.x need a build from source with the v3 profile (see the README). The web flasher installs 1.0.5.

## Files

| File | Size (bytes) | Purpose |
|---|---|---|
| `esp32os.bin` | 5,936,112 | ESP32-OS, 95.3 % of its flash slot; also used by the update over Wi-Fi |
| `esp32os.bin.sha256` | 78 | checksum for the update over Wi-Fi |
| `doomapp.bin` | 1,745,104 | Doom program |
| `quakeapp.bin` | 1,761,232 | Quake program |
| `bootloader.bin`, `partition-table.bin`, `otadata-leer.bin` | 24,160 / 3,072 / 8,192 | first installation |
| `manifest.json` | 1,557 | web flasher format |
| `SHA256SUMS` | 485 | checksums of all files |

## Known issues

- **License of the binary images:** the images combine GPL-2.0 code (NetSurf, KolibriOS) with Apache-2.0 code (ESP-IDF, esp_hosted). Whether binaries may be distributed in this combination has not been settled. The source code in the repository is not affected.
- Wi-Fi passwords are stored unencrypted in flash (no flash encryption, no eFuses).
- The browser has 10.5 MB of memory: 6 to 9 of the 30 test pages run out of JavaScript memory and are shown without JavaScript, pages with more than 512 KB of HTML are cut off. No rounded corners, shadows, transitions or CSS grid. On html.duckduckgo.com the logo is missing.
- The PDF viewer shows text in the system font, opens files up to 4 MB and does not decode CCITT, JBIG2 or JPEG 2000 images.
- All programs share one address space. A faulty program is stopped and reported, but can still disturb the system.
- No battery gauge or camera support. The Wi-Fi co-processor keeps its factory firmware.
