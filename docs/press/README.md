# ESP32-OS press images

Screenshots taken directly from the framebuffer of a real board (Waveshare ESP32-P4-WIFI6-Touch-LCD-5, 1280 × 720) with ESP32-OS **1.0.5** (development version, not released yet).

Free to use for articles and videos, credit: TheUnkn0wnC0DE / ESP32-OS

## About the project

ESP32-OS is a small desktop operating system for the ESP32-P4 microcontroller, inspired by and partly built on KolibriOS. It runs on a 5-inch touch screen with a taskbar, Start menu, windows, an on-screen keyboard and everyday apps such as a file manager, web browser (NetSurf), PDF viewer, music player and weather app. Doom and Quake run as separate programs on the same board. The source code is open (GPL-2.0), and the system can be installed from the browser with the [ESP32-OS web flasher](https://theunkn0wnc0de.github.io/ESP32-OS/).
